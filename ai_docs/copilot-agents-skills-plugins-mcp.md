# Copilot Agents, Skills, Plugins, and MCP

verified_on: 2026-09-14
scope: This page explains how Copilot packages specialized behavior and extra tools; it does not define SSSF's own workflow graph.

- Custom agents are Markdown agent profiles with frontmatter plus instructions. GitHub documents them as specialized teammates that can carry prompts, tool restrictions, and MCP server configuration, and makes them available at repository, organization, enterprise, or user scope depending on location; source: [About custom agents](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/about-custom-agents) and [Using GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli/overview).
- Skills are lighter-weight, task-triggered capability bundles. GitHub documents project skill locations as `.github/skills`, `.claude/skills`, or `.agents/skills`, and personal skill locations as `~/.copilot/skills` or `~/.agents/skills`; source: [About agent skills](https://docs.github.com/en/copilot/concepts/agents/about-agent-skills) and [Adding agent skills for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-skills).
- The open Agent Skills spec is the portability baseline for `SKILL.md`: required `name` and `description`, optional metadata such as `license`, `compatibility`, and experimental `allowed-tools`, plus room for scripts and references beside the skill file; source: the [Agent Skills specification](https://agentskills.io/specification).
- Plugins are the distributable package that can bundle multiple customization types together. GitHub's plugin docs list custom agents, skills, hooks, MCP servers, and LSP configuration as plugin components; source: [About GitHub Copilot plugins](https://docs.github.com/en/copilot/concepts/agents/about-plugins).
- Agent Plugins 1.0 is the portable plugin core to target for new work. GitHub says a new portable plugin should declare the Agent Plugins `$schema`, keep the manifest at `plugin.json`, discover skills from `skills/`, discover MCP configuration from `mcp.json`, and place Copilot-only components under `com.github.copilot/`; source: [About GitHub Copilot plugins](https://docs.github.com/en/copilot/concepts/agents/about-plugins), the [CLI plugin reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-plugin-reference), and the [Agent Plugins 1.0 specification](https://github.com/agentplugins/agent-plugins-spec/blob/main/spec/1.0.0.md).
- Copilot CLI's operational plugin surface is `copilot plugin ...`, including install, list, update, enable, disable, and marketplace management. The CLI also split cross-kind management into dedicated `copilot mcp`, `copilot skill`, `copilot instruction`, and `copilot lsp` commands rather than overloading plugin commands; source: the [CLI command reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-command-reference), the [CLI plugin reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-plugin-reference), and [Finding and installing plugins for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/plugins-finding-installing).
- MCP servers are the tool-bridge to external systems. GitHub documents `copilot mcp add`, user config in `~/.copilot/mcp-config.json`, project config in `.mcp.json` or `.github/mcp.json`, and server transport choices (`stdio`, `http`, `sse`); source: [Adding MCP servers for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers) and [Comparing GitHub Copilot CLI customization features](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/comparing-cli-features).
- One MCP surface is explicitly experimental today: GitHub marks `/mcp search` as experimental and requires `--experimental` or `/experimental on` before using it. That is the right model for later SSSF adoption too: optional convenience features stay outside the deterministic core until they are pinned and tested; source: [Adding MCP servers for GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-mcp-servers).
- `/fleet` is documented as a Copilot CLI parallel-subagent convenience feature, not as part of the portable Agent Plugins or Agent Skills packaging model. Treat fleet fan-out as an operator/runtime behavior and keep it outside the core ADW contract unless a later task deliberately adds pinned coverage for it; source: [Running tasks in parallel with the `/fleet` command](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/fleet), [About custom agents](https://docs.github.com/en/copilot/concepts/agents/copilot-cli/about-custom-agents), and the [Agent Plugins 1.0 specification](https://github.com/agentplugins/agent-plugins-spec/blob/main/spec/1.0.0.md).
