# GitHub Copilot Python SDK Reference

verified_on: 2026-09-14
scope: This page covers the official Python SDK lifecycle and configuration surface, not SSSF-specific envelopes, gates, or write policy.

- The official SDK is `github-copilot-sdk`; the Python README documents `pip install github-copilot-sdk`, the optional telemetry extra, and `python -m copilot download-runtime` for staging the pinned runtime bundle the SDK manages. Primary sources: the [Copilot SDK repository](https://github.com/github/copilot-sdk) and the [Python README](https://github.com/github/copilot-sdk/blob/main/python/README.md).
- `CopilotClient` is the main lifecycle entry point. The documented options include runtime connection selection, `working_directory`, `base_directory`, `session_idle_timeout_seconds`, `enable_remote_sessions`, and SDK-managed cleanup through `start()`/`stop()` or async context managers; see the [Python README](https://github.com/github/copilot-sdk/blob/main/python/README.md).
- `create_session()` and `resume_session()` are the durable session entry points. The Python SDK exposes model selection, reasoning effort, working directory, tools, permission handlers, memory, infinite sessions, MCP servers, custom agents, default-agent policy, skill directories, and disabled skill/server lists through the public client surface; see the [Python README](https://github.com/github/copilot-sdk/blob/main/python/README.md) and the source of [`python/copilot/client.py`](https://github.com/github/copilot-sdk/blob/main/python/copilot/client.py).
- The SDK can expose both built-in and custom tool surfaces. The README documents `@define_tool`, manual `Tool(...)` definitions, and MCP tool naming conventions for `available_tools`, `excluded_tools`, and custom-agent tool lists; see the [Python README](https://github.com/github/copilot-sdk/blob/main/python/README.md) and the repository source in [`python/copilot/client.py`](https://github.com/github/copilot-sdk/blob/main/python/copilot/client.py).
- Disconnect and abort are distinct lifecycle controls. `disconnect()` releases in-memory handlers while preserving resumable session data, whereas `abort()` cancels the currently processing message but keeps the session alive for later prompts; see the [Python README](https://github.com/github/copilot-sdk/blob/main/python/README.md) and [`python/copilot/session.py`](https://github.com/github/copilot-sdk/blob/main/python/copilot/session.py).
- The published docs are sufficient to build against, but later tasks should still pin a concrete SDK/runtime pair and verify behavior against that pair because the port depends on exact lifecycle semantics, not just broad feature claims. The authoritative sources for that validation are the [Copilot SDK repository](https://github.com/github/copilot-sdk), the [Python README](https://github.com/github/copilot-sdk/blob/main/python/README.md), and the exact source files under `python/copilot/`.

Refresh from the README and the public Python source files above before changing session configuration, tool wiring, or cleanup behavior.
